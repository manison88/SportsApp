Idea: Together. People who went to the same game merge their night into one match report. The match-report layout (pinned game-clock timeline, spine of key-play cards) gains a second layer: each person's photos sit on the shared clock in their own color (Sam amber, Chris yellow, Jordan blue), with a name and a dot on every thumbnail.
Why: a night at the game is shared, but today everyone's photos are stranded in separate camera rolls. "Chris took the best one" is the line friends send each other; the merged recap is a share card that markets Witness to the other two people.
First use / empty state: appears only after a game is found (v1) and only if someone else is detected (a tagged companion or an opened invite link). No one detected: nothing shows; the game page offers "Invite someone who was there". A Together memory with nobody sharing yet is just your normal report with a muted "Waiting for Chris and Jordan" track.
Privacy: default share is NOTHING (v1). Photos stay on the phone; only photos the person picks (v3) are uploaded, and only to people in that memory. "Everyone sees only what each person shares. Remove any time." Removing a photo removes it from everyone's view and the recap. Matching stays on-device; the server only sees the minute and the photo the person chose to share. Kids' accounts never appear.
Plugs into: game page (invite sheet after discovery, "Together" avatar pill replaces the share slot in the match-report nav), match report (extra tracks, combined strips, "Who was where" from seat data), You tab (a Together shelf), Timeline (small stacked avatars on the game card).
Minimum backend: identity (Apple sign in, name, color), memory = {gameId, members[]}, invite link, per-member shared photo set (object storage + timestamp, no GPS), membership and revoke endpoints, recap card render on-device from shared photos.
Files: v1 invite, v2 shared report at 42', v3 pick-photos sheet, v4 merged recap card (extra screen so the sheet and the card each get a full screen). build.py regenerates all four.
