# Timeline view modes (60 sample games, 2014-2026). Screens in png/, contact sheet png/overview.png
Switcher: one 40pt pull-down button in the nav bar (icon + view name + chevron). Sport chips live on their own row below and apply to every view; the choice persists per device. Open menu: `00-switcher/v1`. Closed + filter: `v2`. Rejected alternatives (segmented icons, floating pill): `v3`.
**Default: Season shelf.** Photo-led like today's cards, one gesture, and it scales (a page is one year). **Ship first: Season shelf + Cover mosaic** (emotional front door + power-user density). Then Calendar, Strip, Tickets, Map. Cards stays as a 7th "classic" entry.
## Views (games = comfortable range)
1. **Season shelf** (5-400). Poster page per year, finals promoted to a 2x2 tile, year rail doubles as pager. Swipe = year, tap rail = jump. States: 1 game = one big tile + "next game" ghost (`07-states/v1`); 0 games = ghost poster + two CTAs (`v2`); hundreds = page grid scrolls vertically, tiles stay 112pt. SwiftUI: `ScrollView(.horizontal)` + `LazyHStack`, `.scrollTargetBehavior(.paging)`, page = `LazyVGrid` / `Grid` with `gridCellColumns(2)` for the big tile.
2. **Calendar heat map** (20-1000). 12 mini-months, game days lit in sport color, tap a day to peek a card (`02`). Gestures: chevrons/swipe = year, tap month = month zoom with 44pt days (14pt cells are a glance, not a tap target). Empty year = unlit grid; one game = a single lit dot. SwiftUI: `Canvas` for dots, one `Path` hit-test (`SpatialTapGesture`), `matchedGeometryEffect` from month to month view. Cache one `Image` per month.
3. **Cover mosaic** (30-5000). Years / Months / All via pinch or the zoom pill (`03`), finals get 2x2, pin on other big games. Empty months collapse; no-photo games get a tinted score tile. SwiftUI: `LazyVGrid` with 3/4/5 `GridItem`s driven by `MagnifyGesture`, `matchedGeometryEffect` year tile to month grid. Use downsampled thumbnails (ImageIO) and `.drawingGroup()` only on tiles with overlays.
4. **Ticket wallet** (3-40). Newest stub expanded, older ones stacked with sport edges (`04`). Drag = fan through (each stub rises to the front), tap = open memory. Beyond ~40 it should collapse to a year stack. SwiftUI: `ZStack` + `.offset` driven by scroll position, `visualEffect` for depth; render only 8 stubs. Empty: show a blank stub.
5. **Map scrubber** (10-300). Globe on top, time scrubber under it, one card below (`05`). Dragging the thumb moves the pin and swaps the card; later venues ghost. Gestures: drag thumb, tap pin, long-press tick for the nearest big game. Chicago pins overlap, so cluster venues past ~25 and zoom on tap. SwiftUI: MapKit `Map` + `MapPolyline`, or a `Canvas` orthographic globe; scrubber is a `Slider`-like `DragGesture` snapping with `.sensoryFeedback(.selection)`.
6. **Scoreboard strip** (20-2000). Month rows, each a film strip of score bugs; the densest scan (`06`). Swipe a strip sideways, tap a bug to select, readout docks above the tabs. SwiftUI: `LazyVStack(pinnedViews: .sectionHeaders)` of `ScrollView(.horizontal)` rows with `scrollPosition`. Cheapest view: no images.
## Rules shared by all views
- Photo-less games always get a tinted score tile; scores are text, never baked into images. Rooted team is listed first, winner score bold.
- Big games: small shield pin + event name text + 3-color ribbon (own shapes, event palette; no logos). Finals = 2x2/hero tier, other playoffs = pin only.
- Perf: one shared thumbnail cache (3 sizes), `LazyVGrid`/`LazyVStack` only, no `blur` over scrolling content except the nav and zoom pill materials. Keep view state in one `@AppStorage("timelineView")` and the filter in the model so views swap without refetching.
- Accessibility: every tile is one element ("World Series Game 5, Cubs 3, Indians 2, Oct 30 2016, big game"); calendar and scrubber expose `accessibilityAdjustableAction` (next/previous game) instead of dots; sport is never color-only (dot + name in chips, abbreviations in bugs); respect Reduce Motion (no fan/zoom springs, cross-fade); minimum text 12pt, Dynamic Type up to XL in the strip and menu rows.
