# Film strip
Idea: the photo is the screen. Under it a video-editor filmstrip is the timeline: thumbnails sit on the game's own clock (phase bands, goal/key-play ticks with minutes, a running score tape), with a fixed amber playhead and a wall-clock pill. One caption line answers "what was happening" ("44' · BIH 2–1 · 2 min after Al Haydos pulled one back").
Gestures: drag the strip horizontally and it snaps photo to photo (haptic tick, hero cross-fades, caption, score tape and nearest play update); tap a thumbnail to jump; tap a tick to jump to that play's nearest photo; drag the mini overview (Arriving / The game / Leaving) to cover a whole day fast; "Best photo" jumps to the share pick; "All plays" expands the complete list in a sheet (each row jumps the strip); Share exports the current photo with its score and minute.
No win-probability sports (soccer, F1): the backbone is just the clock, phase bands and score tape. Baseball/football/basketball/hockey add a thin win-probability layer above the ribbon (v2), purely optional.
0-2 photos: the strip becomes a wall-clock axis (before / match / after) with big thumbnails, a dashed "+" slot, an honest "no play-by-play" card with "+ Goal" so the fan can mark what they saw; zero photos shows only the empty axis with the add slot.
SwiftUI: ZStack { Image.resizable().scaledToFill() ignoresSafeArea; LinearGradient scrim; VStack { TopBar (glass score bug); Spacer; CaptionView; MiniMap Canvas; FilmStrip } }. FilmStrip = ScrollView(.horizontal) + LazyHStack with .scrollTargetBehavior(.viewAligned) and .scrollPosition(id:), contentMargins = half width so the centred playhead overlay stays fixed; bands and ticks drawn in a Canvas behind the LazyHStack using the same piecewise clock mapping; WP line is a Path in that Canvas. Plays: collapsed row + .sheet(.presentationDetents([.medium, .large])).
