# europe-basketball-volleyball notes
Status: PARTIAL, not complete. Validator: 166 teams (110 basketball, 56 volleyball), 49 leagues, 121 missing venues, 0 errors (teams, leagues and venues/validate.py).
Prefixes: eurbb-<cc>-<code> (basketball), eurvb-<cc>-m|w-<code> (volleyball, men and women are separate leagues). League keys such as basketball/esp.acb, volleyball/ita.superlega.
Validator changes: added "volleyball" to SPORTS in Tools/teams/validate.py and Tools/venues/validate.py; teams/validate.py now also accepts league teamIds that exist in any other *-teams.json or the catalog (needed to list existing EuroLeague/ACB ids).
Already present (reused, listed in teamIds only): EuroLeague 20 (eurol-*), acb-* 7 (+4 EuroLeague clubs in ACB), bsl-* 4, lba-* 6, bbl-* 7, lnb-* 6, gbl-* 3, aba-* 4, lkl-* 3, bsl-il-* 2. League records with the same key as other-sports-leagues.json supersede/union with them (esp.acb, tur.bsl, ita.lba, ger.bbl, fra.lnb, gre.gbl, aba, ltu.lkl, isr.bsl, srb.kls).
Sources: NONE of the club data was verified on the web. Membership (2026-27 is my best knowledge of 2025-26 plus expected changes), colors, abbreviations, founding years are from my own knowledge (no ESPN coverage for these leagues). Wikidata/ESPN ids are null.
Venue coordinates: OpenStreetMap Nominatim search for "<arena>, <city>, <country>" (cache in scratchpad). A venue is kept only if the hit is within 15 km of the city; venues within 400 m of an existing catalog venue with a matching name token (or <=150 m for an indoor venue) reuse the existing id.
Capacity, opened, region are null for the new venues; aliases empty. Time zone from the league country.
