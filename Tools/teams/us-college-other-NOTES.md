# us-college-other notes
Scope: NCAA Division I hockey (men 64, women 45, all located), baseball, softball, women's volleyball, men's and women's soccer. Validator: 1346 teams, 160 leagues, 825 missing venues, 0 errors.
Counts: baseball 295/305, softball 202/308, volleyball 317/348, men's soccer 164/213, women's soccer 259/349, men's hockey 64/64, women's hockey 45/45. 272 existing catalog venues reused, 825 new venues.
Ids: col-<tag>-<espn abbreviation>; tags hockey, whockey, baseball, softball, volleyball, soccer (men), wsoccer (women). NEW sport strings: volleyball (and lacrosse allowed in validate.py, which I edited; Tools/venues/validate.py already had volleyball). Softball uses sport 'baseball' (no softball string exists); its leagueKey baseball/college-softball and ids col-softball-* separate it.
Leagues: one per conference per sport, key <espn base path>/<conference slug> (e.g. baseball/college-baseball/sec); espnPath is the shared ESPN base path (hockey/mens-college-hockey, hockey/womens-college-hockey, baseball/college-baseball, baseball/college-softball, volleyball/womens-college-volleyball, soccer/usa.ncaa.m.1, soccer/usa.ncaa.w.1; all verified to list teams). tier=1 everywhere.
Passport caveat: a league lists only teams whose venue was located, so conference counts are lower than the real membership (the skipped teams are below); do not show 'x of N' as complete for baseball/softball/soccer/volleyball.
Sources: membership + conference (2026-27 alignment) + home field/arena from the Wikipedia NCAA D-I baseball, softball, women's volleyball, men's/women's soccer program lists and 2026-27 hockey standings templates / ESPN hockey groups; hockey arenas from my own knowledge cross-checked with ESPN scoreboard home venues; soccer venues = modal ESPN home venue Aug-Oct 2026 (all teams covered).
Coordinates: Wikidata P625 by Wikipedia sitelink or exact label (near campus city only), OSM Nominatim (accepted only if the result name or city matches), Wikipedia REST title search (6 hand-checked), 11 baseball + 18 hockey hand-picked Nominatim/Wikidata hits. Every point was reverse-geocoded to the expected state (0 mismatches) and checked against the campus city; 5 bad Wikidata points dropped, whole-degree/2-decimal points rejected. Treat as ~100-300 m, not survey grade.
Approximate: taffy-abel-arena (46.49,-84.366, Wikidata, 3 decimals), 3M Arena at Mariucci and several hockey rinks use Wikidata rounded points; clearview-arena-at-rmu-island-sports-center is the RMU Island Sports Center point; ritchie-arena (Franklin Pierce women, Winchendon MA) and sullivan-ice-arena (Saint Anselm women, Goffstown NH) are OSM matches of ESPN names; Kobs/Medlar/Hammons etc. from Nominatim.
Venue reuse: matched existing venues by exact name/alias, or <=180 m + name overlap + compatible sport (volleyball may reuse basketball arenas; hockey reuses shared arenas such as Conte Forum, Kohl Center, Mullins Center, Agganis Arena, Value City Arena). Existing venue records were NOT edited, so they lack the new sports/leagues/tenants. Some new venues sit within 10-100 m of a catalog arena on purpose (separate buildings: Walter Brown Arena/Case Gym, Cadet Ice Arena/Clune Arena, Redbird Arena-CEFCU Arena may be the same building).
New-venue sports field: baseball (baseball and softball parks), hockey, soccer, volleyball (gyms used only for volleyball). leagues use the ESPN college paths above.
Colors: ESPN color/alternateColor (hockey feed has none, so school colors came from the same school in the other ESPN feeds); no placeholders. From my memory (not verified): Alaska Anchorage Seawolves, Alaska Nanooks, Assumption Greyhounds, Augustana (SD) Vikings, Bemidji State Beavers, Bentley Falcons, Clarkson Golden Knights, Dallas Baptist Patriots, Delaware Blue Hens, Ferris State Bulldogs, Franklin Pierce Ravens, LIU Sharks, Lake Superior State Lakers, Michigan Tech Huskies, Minnesota Duluth Bulldogs, Minnesota State Mavericks, Northern Michigan Wildcats, Post Eagles, RIT Tigers, Rensselaer Engineers, Saint Anselm Hawks, Saint Michael's Purple Knights, St. Lawrence Saints, UC San Diego Tritons, UMass Minutemen, Union Garnet Chargers.
Names: teamName = ESPN displayName with fixes (Valparaiso Beacons, UMass Minutemen, Xavier Musketeers); locationName = ESPN location. Women's names with 'Lady' follow ESPN, not Wikipedia.
Lacrosse: NOT done (no ESPN college lacrosse team feed, no stable Wikipedia program list reachable). No lacrosse teams, no lacrosse venues. Men's hockey excludes non-D-I names ESPN lists in its conferences (Wayne State, Findlay, Alabama Huntsville, Post, Saint Anselm, Fairfield and Iona club teams); UAH and Wayne State/Findlay membership in CHA is unverified, so omitted.
Women's hockey includes NEWHA's D-II schools (Assumption, Franklin Pierce, Post, Saint Anselm, Saint Michael's) as D-I hockey programs, per the 2026-27 NCAA D-I women's hockey season page. Delaware, UC San Diego, Dallas Baptist: no ESPN record or feed entry, espn id null.
ESPN ids: externalIds.espn is the id in that sport's own feed (ids differ between sports). wikidata and theSportsDb are null for all.
Riskiest: OSM/Wikidata name-matched fields for small softball and soccer fields (possible neighbour of the right field), Seawolf Sports Complex (ESPN name for UAA hockey), AIC at MassMutual Center, Augustana (SD) at Midco Arena, the 2026-27 conference alignment (Metro, Pac-12, American, UAC) copied from Wikipedia lists dated mid-2026.
