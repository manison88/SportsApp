# sched-soccer-europe-east notes (built 2026-10-17)
Totals: 44 league folders, 626 season files (2011-2026), 118,441 games; validator 0 errors. venues-seen 3,464 (1,207 in app catalog); missing-venues.json 1,137 (validator 0 errors).
Sources: ESPN site API (calendar-year `dates=YYYY&limit=1000`; ranges return HTTP 400) for UEFA comps + tur.1, gre.1, rus.1, rou.1 (2016-18, 2020-24), isr.1 (2016-24), cyp.1 (2025): 32,251 games.
 Everything else = api.sofascore.com public JSON (undocumented, no key, <=8 req/s, cached): 86,190 games. ESPN has no pol/cze/svk/hun/bul/srb/cro/svn/bih/mne/mkd/alb/kos/ukr/blr/mda/geo/arm/aze/kaz/est/lva/ltu/and/smr/gib/fro,
 and its rou/isr/cyp/cze feeds are stale or empty outside the seasons above. football-data.org needs a key; Wikipedia season pages carry no dates/venues. Sofascore ids (team, venue, event) differ from ESPN ids: see team-names.json {league:{teamId:name}} to join to the team records.
UEFA: champions/europa 2011-2026 (qualifying rounds exist only for 2011-2019: ESPN omits them from 2020), conference 2021-2026, super_cup 2011-2026, euro 2012/16/20/24 (season=tournament year), weuro 2017/22/25, wchampions 2019-2026 (none before), nations 2018-2026 (edition start year).
 fifa.worldq.uefa and uefa.euroq use the calendar year of the match (cycles span years); euroq 2011 lacks the 2010 games. fifa.friendly: ESPN lists only ~60-150 games a year, so it is NOT complete; kept games with a European venue (or UEFA home team); season = calendar year.
Domestic seasons: league `season` = start year. Postponed/cancelled placeholders are dropped when the game was replayed (same home/away pair); remaining P/C are unplayed (Ukraine 2021 war: 96 C; COVID: smr/aze/bih/mne 2019-20).
Gaps: Kosovo 2011-2015 and Gibraltar 2011-2012 (not on sofascore); Wikipedia not used. Russia 2011-12: ESPN lists 336 of the expected ~352 games (uncertain). rou 2016-18 / gre 2018 / ukr / cze include relegation-playoff opponents (2-game teams).
Venues: ESPN gives venue ids/names only (no coordinates); sofascore gives venueCoordinates only for ~half the venues and none in many leagues/seasons.
 6,231 games have venueId null (no source venue and no safe inference). 33,365 games (28%) have a venue INFERRED from the home team's majority stadium in the same/adjacent season (<=4 years) or its current sofascore stadium (seasons >=2023); their note ends with "venue inferred". Treat as likely, not certain.
 Coordinate sources in venues-seen (`coordinateSource`; absent = taken from the app catalog or Tools/venues / teams missing files): wikidata 730 (P625 via bulk SPARQL, name+city matched), sofascore 499, nominatim 259, sofascore-team (team's current stadium) 171, manual 38 (my own known coordinates, mostly large grounds).
 100 records are flagged `"approximate": true` (name did not match the located stadium, e.g. renamed/demolished/training grounds; city-level accuracy); they are excluded from missing-venues.json. 28 missing-venues have <3-decimal latitude (Wikidata rounding).
 Sofascore coordinates swapped lat/lon for 21 venues (fixed by country-median test); 4 wrong ones (e.g. Dzerzhinsk RU for Belarus, Montana US) were re-resolved by name. ESPN venues whose resolved country did not match were dropped.
 Unresolved (venue dropped from games): about 49 low-use venues (e.g. Kazakh/Kosovo village grounds, some qualifying-round pitches).
Per-team spot check (games per team per season vs 30/34/36/38): all full leagues match; deviations are only COVID/war/curtailed seasons, split-league playoffs or promotion/relegation playoff opponents.
