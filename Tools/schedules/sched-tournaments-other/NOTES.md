# sched-tournaments-other (fetched 2026-10-17)
Totals: 48 leagues, 297 season files, 21,438 games (F 20,582, S 736, C 118, P 2). Validator 0 errors. venues-seen.json 2,269 records (1,409 distinct name+city), 478 linked to the app catalog, missing-venues.json 711 physical venues (0 errors).
Sources: (1) fiba.basketball public game pages (history/<id>/games and events/<slug>/games, embedded JSON: scores, UTC time, venue id/name/city/IANA tz, round/window) for every FIBA national and club competition. (2) ESPN site API (one day per call, ranges return 400): World Baseball Classic, Olympic baseball/ice hockey/rugby 7s, World Cup of Hockey 2016, Rugby World Cup, Six Nations, Women's RWC; ESPN has no data for basketball/fiba before 2023 and no venue for WBC 2013/17 or Olympic hockey 2014/18. (3) Sofascore API for IIHF Worlds and handball (venues only 2015+). (4) Wikipedia wikitext box scores/brackets ONLY to fill venues FIBA/Sofascore lack (WC 2014, Olympics 2012, Americas/Afro/Asia 2011-17, OQT 2012, IIHF Worlds 2011-22, handball WC/Euro/Olympics) and to build FIBA Oceania series 2011-15. (5) EuroLeague API v2 for EuroCup (arena+club city). EuroLeague Final Four venues already complete in sched-pro-basketball.
League keys (folder = key with / -> -): basketball/fiba.worldcup, .worldcupq (pre-qualifiers+qualifiers, all regions), fiba.eurobasket, .eurobasketq, fiba.americup(+q), fiba.afrobasket(+q), fiba.asiacup(+q), fiba.oceania, fiba.oqt (Olympic qualifying), fiba.bcl (Champions League 2016-17 on, incl. qualification rounds), fiba.europecup, fiba.eurochallenge, fiba.bal, fiba.intercontinental, eurocup; a ".w" suffix = women's. Olympics: basketball/mens-olympics-basketball, womens-olympics-basketball (ESPN slugs, FIBA data), hockey/olympics-mens-ice-hockey, -womens-, baseball/olympics-baseball, rugby/282,283 (7s). Others: baseball/world-baseball-classic, hockey/iihf.worlds(.w), hockey/hockey-world-cup, handball/ihf.worldchamp(.w), handball/ehf.euro(.w), handball/olympics.mens|womens, rugby/164205 (RWC), 180659 (Six Nations), 289237 (Women's RWC). Season = year played (Tokyo 2020 = 2021). Qualifier files are keyed by the year the cycle's first game was played; a file can run past 2026 (cycle to WC 2027 = worldcupq/2024, to EuroBasket 2029 pre-qualifiers = eurobasketq/2025).
Team ids: FIBA/IIHF/EHF national = 3-letter code (basketball codes = Tools/teams fibam-<code>, hockey iihf-<code>, handball ehfn-<code>; see team-map.json); FIBA clubs = FIBA organisationId; EuroCup = club code; ESPN leagues = ESPN team ids (app national teams have no ESPN ids; match on abbreviation). Home = source's first-listed team; tournaments mark "Neutral site" when the host country is neither team.

COORDINATES: catalog/other-agent venue files first (683 records), Wikidata label/search checked against city centre <25 km and timezone-country (683), OSM Nominatim (392), same-hall alias (28), Wikipedia (24), manual (8). 451 venue records are APPROXIMATE (coordinates = city centre, "approx": true in venues-seen.json; they are NOT in missing-venues.json): mostly club halls in BCL/Europe Cup/EuroCup/EuroChallenge and small qualifier halls, plus Milano Rho Arena, Nanjing YOG Gymnasium, Quico Cabrera Arena. 12 venue ids have no coordinates at all (Guam, Hong Kong, Leek...) and are absent from venues-seen.
